# Logo

The mark is a donut chart of three slices in the library's palette, with the slice spacing left open. Source files are SVG, `png/` holds the exports.

| File | Use |
| --- | --- |
| `mark.svg` | The mark alone, transparent. Works on dark and light backgrounds. |
| `mark-square.svg`, `mark-square-light.svg` | The mark on a rounded square, for app icons and favicons. |
| `logo-horizontal.svg` | Mark and name for dark backgrounds. |
| `logo-horizontal-light.svg` | Mark and name for light backgrounds. |
| `png/banner.png` | Banner for the README and release pages. |

Colors: teal `#2FB4B6`, green `#5DD39E`, coral `#F97066`, amber `#F5B041`, stage `#0F172A`. The wordmark is Manrope ExtraBold; the SVG falls back to the system sans where Manrope is missing.
